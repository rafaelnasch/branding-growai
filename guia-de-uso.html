Diga a peça, a linha e o objetivo

Peça em português. Sai no padrão.

Com a skill instalada, o Claude já sabe cores, fontes, logo, fotografia, voz, regras de prova e o Radar de Foco. Você só diz o que quer, para qual linha e para quem. Os pedidos abaixo estão prontos para copiar.

01 · Instale uma vez

Três jeitos de instalar, um só pacote.

A pasta precisa se chamar exatamente branding-growai, com o SKILL.md dentro.

Claude Code

Terminal, VS Code, desktop

bash
git clone https://github.com/rafaelnasch/branding-growai.git ~/.claude/skills/branding-growai
claude.ai

Navegador e celular

Baixe branding-growai.zip em Releases no GitHub e envie em Settings › Capabilities › Skills. Lá, todo HTML sai em arquivo único.

Codex

Codex CLI

bash
git clone https://github.com/rafaelnasch/branding-growai.git ~/.codex/skills/branding-growai

04 · Garantias

O que a skill garante. E o que ela recusa.

Garante
  • Cores, fontes e logo certos, na noite e no dia.
  • Newsreader nos títulos, Hanken Grotesk no texto, IBM Plex Mono nos números.
  • Fotografia do banco aprovado, com a grade Noite.
  • Um só ponto laranja e um só botão.
  • Voz que afirma e fala de negócio. Número com fonte; exemplo marcado como exemplo.
  • Página legível no celular, de 320 a 430 px.
Recusa
  • Prometer “10x” ou resultado garantido.
  • Oferecer conversa gratuita.
  • Rosto gerado por IA, pose, aperto de mão, foto fora do banco aprovado.
  • Nome de cliente sem autorização escrita.
  • Ferramenta de terceiro como produto.
  • Sora, Source Sans 3 e JetBrains Mono, que saíram na versão 4.

Toda receita tem um gargalo. Os dados dizem qual.
